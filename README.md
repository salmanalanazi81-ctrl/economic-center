# مركز التميز الاقتصادي واستشراف المستقبل

موقع إلكتروني تفاعلي احترافي لمركز التميز الاقتصادي واستشراف المستقبل في الرياض، المملكة العربية السعودية.

## 🎯 نظرة عامة

هذا الموقع الإلكتروني يمثل العرض الرقمي لمركز التميز الاقتصادي واستشراف المستقبل، وهو مركز رائد يساهم في ازدهار اقتصاد الرياض من خلال توفير معلومات اقتصادية دقيقة وتحليلات استشرافية.

### الرؤية
أن نصبح مركزًا رائدًا في مجال المعلومات الاقتصادية يساهم في ازدهار اقتصاد الرياض.

### الرسالة
تمكين اتخاذ قرارات أفضل في مجال الأعمال والسياسات من خلال توفير معلومات اقتصادية دقيقة وتحليلات استشرافية.

## ✨ الميزات الرئيسية

### 1. **تصميم احترافي وجذاب**
- هوية بصرية متميزة بألوان الأزرق والذهبي والأبيض
- تصميم عصري يعكس الاحترافية والثقة
- واجهة مستخدم سهلة وبديهية

### 2. **تصميم متجاوب بالكامل (Responsive)**
- يعمل بشكل مثالي على جميع الأجهزة (حاسوب، تابلت، موبايل)
- تجربة مستخدم متسقة عبر جميع المنصات
- تحسين خاص للشاشات الصغيرة

### 3. **تفاعلية متقدمة**
- رسوم متحركة سلسة وجذابة
- تأثيرات hover احترافية
- تايملاين تفاعلي للرؤية المستقبلية
- نموذج اتصال تفاعلي مع تحقق من صحة البيانات

### 4. **محتوى شامل ومنظم**
- معلومات واضحة ومختصرة
- بطاقات تنقل تفاعلية
- أيقونات معبرة من Font Awesome

## 📄 صفحات الموقع

### الصفحات المنجزة:

1. **الصفحة الرئيسية (index.html)**
   - قسم Hero جذاب مع الرؤية والرسالة
   - بطاقات تنقل تفاعلية للأقسام الرئيسية
   - قسم الرؤية والرسالة
   - تايملاين الرؤية المستقبلية
   - Call-to-Action

2. **من نحن (about.html)**
   - الرؤية والرسالة بالتفصيل
   - الأهداف الاستراتيجية
   - القيم المؤسسية
   - لماذا تختارنا

3. **خدماتنا (services.html)**
   - الخدمات الأساسية
   - تفاصيل كل خدمة
   - فوائد الخدمات
   - دعوة لحجز استشارة

4. **الدراسات والتقارير (studies.html)**
   - أنواع الدراسات
   - الدراسات المميزة
   - المنهجية البحثية
   - طلب دراسة مخصصة

5. **الاستشراف الاقتصادي (foresight.html)**
   - تعريف الاستشراف
   - خدمات الاستشراف
   - المنهجية
   - المجالات الرئيسية
   - الفوائد

6. **الشراكات (partnerships.html)**
   - فلسفة الشراكات
   - أنواع الشراكات
   - فوائد الشراكة
   - الشركاء الاستراتيجيون
   - نموذج الشراكة

7. **تواصل معنا (contact.html)**
   - معلومات الاتصال (عنوان، هاتف، بريد إلكتروني)
   - نموذج اتصال تفاعلي
   - الأسئلة الشائعة
   - روابط وسائل التواصل الاجتماعي
